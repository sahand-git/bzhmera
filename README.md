# بەرنامەی بژمێرە (Bzhmera) - تۆمارکەری خاڵەکان

ئەپڵیکەیشنێکی مۆبایل-دۆستانە و مۆدێرن بۆ تۆمارکردن و هەژمارکردنی خاڵەکانی دوو یاریزان بە شێوازی کاتیی (ڕاستەوخۆ)، هاوشێوەی ئەپەکانی ژمێریار و خاڵبەندی (بژمێرە).

## تایبەتمەندییە سەرەکییەکان (Features)

1. **ناوەکانی سەردێڕ بە شێوەی دەستکاریپێکراو (Editable Header Names):**
   - دوو خانەی تەنیشت یەک بۆ نووسینی ناوی هەردوو کەسەکە / یاریزانەکە.
   - جێگرەوەی دیاریکراو (Default Placeholders): `کەسی ١` و `کەسی ٢`.
   - بە نووسینی ناوی تایبەت، ناوی سەردێڕی ستوونەکان و بەشی کۆی گشتی یەکسەر نوێ دەبنەوە.

2. **خشتەی خاڵی دینامیکی (Dynamic Score Table):**
   - هەر ڕیزێک پێکهاتووە لە:
     - **خانەی یەکەم:** خانەی ژمارەیی خاڵەکانی کەسی ١.
     - **خانەی دووەم:** خانەی ژمارەیی خاڵەکانی کەسی ٢.
     - **خانەی سێیەم:** خانەی تێکستی تێبینی بە جێگرەوەی `تێبینی...`.
     - ژمارەی ڕیز (بە ژمارەی کوردی) و دوگمەی سڕینەوە بۆ هەر ڕیزێک.

3. **دوگمەی زیادکردنی ڕیز (Add Row Button):**
   - دوگمەیەکی دیار لە خوارەوە بە دەقی `+ ڕیزێک زیاد بکە`.
   - بە کلیک کردن ڕیزێکی نوێ دروست دەکات و یەکسەر فۆکەس دەکاتە سەر خانەی یەکەم.
   - ئەگەر لە خانەی تێبینی دوگمەی `Enter` دابگریت، خۆکارانە ڕیزێکی نوێ دەکرێتەوە.

4. **کۆی گشتی خۆکار و ڕاستەوخۆ (Live Sticky Totals):**
   - پێڕستی چەسپاو لە ژێرەوە (Sticky Footer) بە ناونیشانی `کۆی گشتی`.
   - خاڵی کەسی ١ و کەسی ٢ بە شێوەی ڕاستەوخۆ کۆدەکرێنەوە کاتێک هەر ژمارەیەک بنووسرێت.
   - نیشاندەری پێشەنگی و جیاوازی خاڵەکان (کێ پێشەنگە و بە چەند خاڵ لە پێشە، یان ئایا یەکسانن).

5. **دیزاینی تەواو RTL و مۆبایل:**
   - بەکارهێنانی فۆنتی جوانی `Vazirmatn`.
   - بە قەبارەی گونجاو بۆ پەنجە و شاشەی مۆبایل (Touch Targets > 48px).
   - پاشەکەوتکردنی خۆکار لەناو وێبگەڕ (LocalStorage) تا لە کاتی ڕیفرێشدا داتاکان نەفەوتێن.
